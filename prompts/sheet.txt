# 目的
APサーバ構築手順書を、ソフトウェアごとに1ファイル(1シート)ずつ作成してください。

# 入力ファイル
1. テンプレート:C:\workspace\SystemMigration\templates\APサーバ構築手順書_temp_ver1.xlsx
   含まれるシート:
   - 表紙      :表紙シート
   - 変更履歴  :変更履歴シート
   - 目次      :インストール対象ソフトウェアの一覧と手順の目次。「内容」欄には、対応するシート名を記載する
   - temp      :ソフトウェア別手順書の作成用テンプレートシート
2. 参照元:C:\workspace\SystemMigration\AP\APサーバ構築手順書_1 .xlsx
   (既存の構築手順書。ソフトウェア一覧と各インストール手順の情報源として使用する)

# 作業内容
1. 参照元ファイルを読み込み、インストール対象のソフトウェアを洗い出す。
2. ソフトウェアごとに、テンプレートの「temp」シートの構成、書式、レイアウトをそのまま踏襲して手順書シートを作成する。
   - 参照元の手順、コマンド、設定値、パラメータは、改変や省略をせずに転記する。
   - 参照元に記載のない項目は推測で補わず、「要確認」と記載する。
3. シート名は、ソフトウェア名(例:CSH)とする。
   - Excelの制約に従い、31文字以内で、使用不可の文字(\ / ? * [ ] :)は使わない。

# 出力
- 出力先:C:\workspace\SystemMigration\sheets
- ファイル形式:Excel(.xlsx)
- ファイル名:APサーバ構築手順書_[シート名]_ver1.xlsx
  例:APサーバ構築手順書_CSH_ver1.xlsx
- 各ファイルには、そのソフトウェアのシート1枚のみを含める(表紙、変更履歴、目次、tempは含めない)。
- 再出力時、版数をあげてください。
- まず、APサーバ構築手順書_CSH_ver1.xlsxを作成ください。問題がなければ、残るソフトウェアも同様に作成します。

# 制約・注意事項
- テンプレートファイルと参照元ファイルは変更しない(読み取り専用)。
- 既存の出力ファイルがある場合は、上書きせず、上書きしてよいか確認する。
- 作業完了後、作成したファイルとシート名の一覧を報告する。












# 依頼
AP サーバ（RHEL 8.10）の「ユーザ・グループ」構築手順書を、定義書の内容に基づいて作り直し、ver2 として新規作成してください。

# 入力
- 定義書：C:\workspace\SystemMigration\AP\環境定義書(icwaq01w).xlsx
  - 「OSユーザ一覧」シートに、ユーザ・グループの定義情報（ユーザ名、UID、グループ名、GID、補助グループ、ホームディレクトリ、ログインシェル、備考など）がある。

# 出力
- C:\workspace\SystemMigration\sheets\APサーバ構築手順書_ユーザ・グループ_ver2.xlsx として新規保存する。
- ver1 は変更せず、そのまま残す。

# 作成方法
1. 「OSユーザ一覧」シートを全行読み、列の意味を確認する。
2. 手順表は次の順に作る。
   - 事前確認：既存のユーザ・グループ、UID・GID の重複がないかを確認する（id、getent group）。
   - 作業：グループを先に作成し（groupadd -g <GID> <グループ名>）、次にユーザを作成する（useradd -u <UID> -g <グループ> -G <補助グループ> -d <ホーム> -s <シェル> <ユーザ名>）。定義書の 1 グループ・1 ユーザにつき 1 行とする。
   - 事後確認：id <ユーザ名>、getent passwd <ユーザ名>、getent group <グループ名> が定義書と一致することを確認する。
   - 切り戻し：userdel、groupdel（ホームディレクトリの扱いは備考に書く）。
3. コマンドは 1 セルに 1 コマンドとし、定義書の値をそのまま記載する。環境ごとに変わる値は <> で囲む。
4. パスワードなどの機密情報は転記せず、<パスワード> とする。
5. 定義書にない項目、読み取れない値、判断に迷う点は推測せず、セルに【要確認】と記載する。

# 守ってほしいこと
- 定義書または「OSユーザ一覧」シートが見つからない、または読めない場合は、作業を止めて報告する。
- 保存後にファイルを開き直し、シート名、入力規則、フィルタ、ウィンドウ枠、印刷設定を確認する。

# 完了報告
- 保存したファイルのフルパス
- 定義書から取り込んだユーザ・グループの一覧（件数を含む）
- ver1 からの変更点
- 【要確認】の一覧
